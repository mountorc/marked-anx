Marked ANX Component Usage

This demo shows how to use the marked-anx-component custom element in other pages.

Example 1: Load Markdown from URL

Using the src attribute to load markdown from a URL

<marked-anx src="/examples/demo.md"></marked-anx>

Example 2: Pass Markdown directly

Using the tag content to pass markdown content directly

<marked-anx># Hello
This is a **test** of the marked-anx component.

:::anx
{
"kind": "box",
"title": "Test Box",
"data": [
{ "name": "Item 1", "value": "Value 1" },
{ "name": "Item 2", "value": "Value 2" }
],
"html": "<div>{{name}}: {{value}}</div>"
}
:::
</marked-anx>
